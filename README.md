Site institucional premium para uma oficina mecânica, com foco em gerar contato via WhatsApp, apresentar os serviços e divulgar os conteúdos das redes sociais.

## ✨ Sobre o projeto

Site desenvolvido do zero, com identidade visual **preta e dourada** inspirada na logo do cliente. Layout responsivo (adaptado para celular, tablet e computador), menu lateral fixo e botões de contato direto pelo WhatsApp.

## 📄 Páginas

- **Início** — apresentação da oficina, serviços, diferenciais, horário e localização (Google Maps)
- **Veículos à venda** — vitrine dos carros disponíveis
- **Dicas para seu carro** — dicas de manutenção em layout ilustrado
- **Vídeos** — vídeos do YouTube e galeria do Instagram
- **Trabalhe Conosco** — formulário de candidatura (envia pelo WhatsApp)
- **Orçamento** — formulário de pedido de orçamento (envia pelo WhatsApp)

## 🛠️ Tecnologias

- HTML5
- CSS3 (layout responsivo, sem frameworks)
- JavaScript (menu, integração com WhatsApp e player de vídeos)
